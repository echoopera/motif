# Motif Style Lab — Pro enhancements

Recommended Sep 28, 2026. Ten enhancements, in priority order. Start with 1, 2, 5 and 6.

1. **Keyframe any parameter.** A keyframe lane under the scrubber so any control can change over the loop (burst builds from 0 to 1, palette shifts at a set moment). Today every control is a single value for the whole clip — the biggest gap for professional work.
2. **Layer styles.** Stack two or three styles with blend modes, masks and per-layer opacity (e.g. Plexus behind Particle Form over Halftone).
3. **Custom text and fonts.** Upload OTF, TTF or WOFF2; animate variable-font axes in the canvas; multi-line text and alignment; SVG logos and artwork so particles can form a brand mark.
4. **Match colour to the brand.** Palette editor with brand swatches, per-colour locks, palette-from-image; colour-managed export (sRGB, Display P3, Rec.709) and a broadcast-safe limiter.
5. **Motion blur and a finishing stack.** Shutter-angle motion blur, glow, chromatic offset, depth-varying blur, levels and a gradient-map grade.
6. **Pro delivery formats.** ProRes 4444 and DNxHR, true alpha exports, broadcast frame rates with drop-frame timecode, a render queue across aspect ratios or saved looks, and a flash limiter.
7. **Faster engine for heavy styles.** Move Flow Field, Orbital Swarm, Metaballs and Particle Form to WebGPU: particle counts from thousands to hundreds of thousands, smooth 4K previews.
8. **Audio and beat sync.** Load a track, detect tempo, snap loop length to bars, map audio bands to any parameter, optional live input — links to Motif Live mode.
9. **Comparison and the Evolve family tree.** Grid view of all 25 styles live, A/B split compare, an Evolve family tree to revisit or cross two parents, ratings and tags on saved looks.
10. **Hooks into Motif and the agent studio.** Presets import into the Motif scene format; expose the lab over MCP so the 16 studio agents can drive it (Director picks, Critic scores, Delivery exports); shared look library.
