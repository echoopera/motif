# Design Canon — the studio's taste, written down

Taste is a set of preferences with costs. Every principle here names what it sacrifices.

## Lineage (by name, from memory — no external references)
Dieter Rams (less, but better) · Teenage Engineering (instrument-grade objects, playful precision) · Apple HIG (deference, clarity, depth) · Linear (density with calm, keyboard-first) · Stripe (typographic authority, restraint) · IBM Carbon (systematic rigour) · Shopify Polaris (merchant empathy) · Braun/ Vitsœ (proportion) · Swiss typography (grid, hierarchy) · Frog and IDEO era studios (research-led, client-embedded).

## Principles
1. **One thing per screen.** The user's reason for arriving is the most obvious element. Sacrifices: feature visibility.
2. **Hierarchy before decoration.** Size, weight, position, contrast — in that order. Colour last. Sacrifices: brand expressiveness on utility screens.
3. **Rhythm over rules.** A consistent spatial scale (4 pt base) and optical alignment beat mathematically perfect but visually wrong alignment. Sacrifices: pixel-perfect symmetry.
4. **Native first, brand second.** On Apple platforms, feel Apple. On the web, feel like the web. Brand lives in type, colour, voice and motion personality, not in reinvented controls. Sacrifices: cross-platform sameness.
5. **Motion explains.** Every animation tells the user where something came from or went. Decorative motion is cut. Sacrifices: spectacle.
6. **Density is a dial the user holds.** Offer comfortable and compact. Never decide for a power user. Sacrifices: one canonical look.
7. **States are the design.** Empty, loading, error, overflow, unbounded, offline, permission-denied. The default state is the easy part. Sacrifices: speed to first mock.
8. **Copy is interface.** A button label is a design decision. Errors say what happened and what to do next. Sacrifices: brevity when clarity needs a second sentence.
9. **Delight is earned once.** One moment of surprise per product, placed where success happens. Sacrifices: charm spread everywhere.
10. **Restraint.** If it could be removed without loss, remove it. Sacrifices: the comfort of "complete-looking."
11. **Instrument-grade for creative tools.** Immediate response, visible state, physical metaphors only where they add precision. Sacrifices: novelty.
12. **Accessible is not a mode.** Contrast, targets, focus, motion safety and scaling are the default design. Sacrifices: some visual extremes.

## Reference metrics we hold ourselves to
- Aesthetic bar: better than the best consumer app on the target platform.
- Primary action reachable in one gesture from the start screen.
- Nothing on screen a first-time user cannot name.
- Every screen passes the squint test (hierarchy survives blur) and the 5-second test (purpose is stated in 5 s).
