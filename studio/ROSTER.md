# Roster — select the smallest qualified team

## Leadership and client

| Agent | Activate when | Owns |
|---|---|---|
| studio-director | New engagement, direction conflict, stage decision, go/no-go | Direction model and stage decisions |
| engagement-lead | Intake, client-facing review, commitments, handoff, aftercare | Brief and client-facing artifacts |
| producer | Work decomposition, lanes, stubs, claims, collisions | Work orders and execution ledger |
| design-director | Cross-lane craft, consistency and taste decisions | Design review record |
| creative-director | A project needs a clear concept or multiple directions | Direction artifacts |

## Routing rules

- Begin with the Engagement Lead and Studio Director.
- Add one platform specialist for each materially different platform behavior.
- Add one domain specialist when expert workflow changes the interaction model.
- Add Design Systems when UI will be reused, themed, scaled or implemented on multiple surfaces.
- Add risk specialists only when the brief activates their risk.
- Keep Verifier independent from the owner of the work being verified.
- If one agent plays several roles sequentially, name the role used for each artifact.
