# State Completeness
States: default · empty · loading · error · overflow (too much content) · unbounded (content with no natural end) · offline · permission-denied · (creative tools) armed/recording/modal-tool.
For each: what is shown, what can be done, what the copy says, what motion plays, what the screen reader announces.
A missing state is a bug. File it as one.
