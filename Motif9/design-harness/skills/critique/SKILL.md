# Critique
1. Five-second look per screen: write "it is ___, I would ___" before analysing.
2. Fill `harness/templates/critique.md`: rubric scores, top-three notes as observation → impact → fix, what works (specifically).
3. HALT lists: platform, genre, ethics, accessibility. Any hit → fail.
4. Verdict with target stage and owner for loop-back.
5. File to `harness/state/reviews/`; repeat findings → craft ledger.
