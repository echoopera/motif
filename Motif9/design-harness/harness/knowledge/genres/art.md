# Art & Creative Tools — Domain Intelligence

## Users
Illustrators, designers, 3D modellers, photographers, animators, hobbyists. Two speeds: explore (loose, fast) and refine (precise, layered).

## Core objects
Canvas, layer, tool, brush/stroke, selection, transform, colour, asset, history, document, export preset.

## Principles
- The canvas is sacred: never obscured, never lagging, always zoomable/pannable with the same gesture everywhere.
- Tool state is always visible: active tool, colour, size, opacity, blend, layer.
- Non-destructive by default; destructive by explicit choice.
- Precision on demand: numeric entry, snapping, guides, constrain modifiers — discoverable, not mandatory.
- History is a first-class view, not just a shortcut.

## Patterns
| Need | Pattern |
|---|---|
| Tools | Vertical palette, grouped, long-press for variants, quick-switch by keyboard/pencil gesture |
| Properties | Contextual inspector for the selected object; sliders with numeric entry; colour picker with swatches, wheel and hex |
| Layers | Reorder by drag, group, lock, hide, blend, opacity; thumbnails live |
| Transforms | Handles with constrained and free modes; numeric panel |
| Colour | Harmonies, recent, document palette, eyedropper anywhere |
| Export | Presets by destination; preview matches output |

## Input specifics
Pencil: pressure → size or opacity (user choice), tilt → shading, hover → preview cursor. Touch: two-finger undo, three-finger redo, pinch zoom, palm rejection assumed. Pointer: scroll zoom, space-drag pan, right-click context.

## Visual language
Neutral, low-chroma chrome so the artwork's colour reads true. Mid-grey canvas surround. Chrome opacity user-controllable in focus mode.

## HALT
Canvas obscured · Zoom gesture inconsistent between views · Destructive default · Tool state hidden · Export preview ≠ output.
