# macOS platform sheet

## Product character

macOS favors persistent workspaces, resizable windows, precise pointer input, keyboard efficiency, discoverable menus and multi-document continuity. It is not an enlarged iPad layout.

## Required decisions

- window model: single, multi-window, document-based, utility panels or menu-bar surface;
- sidebar, toolbar, inspector and content hierarchy;
- menu commands and keyboard shortcuts for primary verbs;
- selection, focus, context menus, drag/drop and multi-selection;
- minimum/ideal window sizes and behavior while resizing;
- full-screen, split view, multiple displays and restoration;
- file/document ownership, autosave, versions, export and recovery;
- accessibility semantics, Full Keyboard Access, text scaling and contrast;
- density and target sizes appropriate to pointer plus touch alternatives where relevant.

## Quality checks

Verify at minimum and large window sizes, keyboard-only operation, pointer/trackpad, long content, appearance modes, document reopen/restoration, multiple windows and destructive recovery. Preserve native command placement unless a documented task need justifies custom behavior.
