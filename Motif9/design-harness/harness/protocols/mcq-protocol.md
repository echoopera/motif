# MCQ Protocol (client questions)

Every question the studio asks a client is one multiple-choice question.

## Rules

1. One question per turn. Never two.
2. 2–4 options. Mutually exclusive. Each one a real, defensible choice.
3. Each option carries a one-line consequence ("→ faster, less flexible").
4. Always include the studio's recommendation, marked, with a reason.
5. An "Other — tell me" escape hatch is allowed only as the last option and only when the space is genuinely open.
6. Ask only when the answer changes the work. If we can decide and reverse cheaply, decide and note it in the DDM.

## Format

```
Q: <question in one sentence>
A) <option> → <consequence>
B) <option> → <consequence>   ◀ recommended: <reason>
C) <option> → <consequence>
```

## Where it applies

Intake, direction selection, scope trade-offs, review sign-off, any blocker that needs the client.

## Where it does not apply

Internal agent-to-agent communication. Agents decide and log; they do not interview each other.
