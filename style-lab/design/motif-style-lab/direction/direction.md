# Direction — Instrument Bench

**Thesis.** A quiet graphite workbench where the canvas is the only loud thing. It feels like a hardware instrument: labelled, precise, every value visible.

## Five rules (and what each sacrifices)
1. **Canvas is sacred.** Mid-grey surround, never obscured except by the Evolve grid the user opened. *Sacrifice:* no floating HUD over the art.
2. **Every control shows its value.** Sliders carry numeric readouts; selects show the current option. *Sacrifice:* denser panel.
3. **Every change is undoable.** No confirmation dialogs. *Sacrifice:* history memory.
4. **Mono labels, sans values.** JetBrains Mono uppercase for labels and readouts; Instrument Sans for names and copy. *Sacrifice:* less typographic flourish in chrome.
5. **One accent.** Cobalt marks focus, active and primary; amber marks locks and keyframe-like moments. *Sacrifice:* no category colour-coding.

## Will not do
Colourful chrome · onboarding tours · modal on load · text inside the canvas for UI · animation in the chrome beyond 150 ms feedback.

## References (name only)
Cavalry — parameter-first procedural thinking · TouchDesigner — live, always-running canvas · Teenage Engineering — labelled, confident hardware panels.

**Motion personality:** snappy, exact, calm. **Voice:** direct, technical, friendly.
**Proof screen:** the workspace with Particle Form selected and Evolve open.
