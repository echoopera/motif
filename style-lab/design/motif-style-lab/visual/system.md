# Visual grammar

- **Type roles:** `display` Anybody 700 (style name in inspector), `body` Instrument Sans 14/20, `label` JetBrains Mono 11 uppercase +0.08em, `readout` JetBrains Mono 12 tabular.
- **Colour (semantic):** surface-0 app ground, surface-1 panels, surface-2 raised controls, stage-surround mid-grey, text, text-muted, line, accent (cobalt), accent-ink, lock (amber), danger. Light and dark themes; chrome chroma ≤ 0.02 except accent and lock.
- **Grid:** 3 columns: library 272, stage fluid, inspector 320; 8-point spacing scale; 1-pixel hairlines.
- **Iconography:** text glyphs only (▶ ❚❚ ↺ ↻ ⚿ ✕); no icon font.
- **Artwork palettes:** 10 named palettes (bg, ink, three accents) owned by tokens; artwork never uses chrome tokens.
- **Content bounds:** style names ≤ 18 characters; blurbs ≤ 90 characters; text params ≤ 40 characters.
