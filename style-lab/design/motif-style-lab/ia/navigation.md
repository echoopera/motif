# Navigation

Single workspace, no routes.

| Region | Contents | Keyboard |
|---|---|---|
| Top bar | Product mark, aspect segmented control, quality, play/pause, time, Export | 1–6 aspect, Space, X export |
| Library (left) | Search, category chips, 25 style rows with thumbnails | [ ] previous / next style |
| Stage (centre) | Canvas, guides overlay, scrubber | ← → step frame, G guides |
| Inspector (right) | Style header, action bar (Mutate, Evolve, Randomize, Reset, Undo, Redo), groups: Style, Colour, Motion, Finish, Saved looks | M, E, R, ⌘Z / ⇧⌘Z, S save look |
| Evolve (overlay on stage) | 6 live children, strength, Breed again, Close | E, 1–6 keep, Esc |
| Export (dialog) | Format, size, fps, loops, background, progress | Enter render, Esc cancel |
| Shortcuts (dialog) | Full shortcut list | ? |

Recovery: every change is undoable; Evolve and Export close with Esc without side effects.
