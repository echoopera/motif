# Motif

Browser-based, prompt-directed procedural animation studio for type, shapes, particles and physics. Directed from Claude Code, Codex or VS Code through a local MCP bridge, built by 16 studio agents, tuned on a timeline, shipped to broadcast, Lottie, web and live.
