# Motif

Browser-based, prompt-directed procedural animation studio for type, shapes, particles and physics. Directed from Claude Code, Codex or VS Code through a local MCP bridge, built by 16 studio agents, tuned on a timeline, shipped to broadcast, Lottie, web and live.

## Contents

| Folder | What |
| --- | --- |
| `docs/` | PRD & Engineering Spec (md, docx, pdf), Competitive landscape (md, pdf), Style Lab pro enhancements |
| `site/` | Marketing one-pager (`motif-one-pager.html`) |
| `style-lab/` | Motif Style Lab — 25-style parametric playground: full source, design specs, build script, tests, and `dist/standalone.html` |
| `agent-motif/` | AgentMotif: shader director agent for SDK 4.0 (image/description → real-time Motif kit styles, effects, transitions, sequences), GLSL library, look-dev toolchain (analyze, compare, tune, qa, film), knowledge base, showcase kit 2.0 |

| `agent-skills/` | 16 studio agent skills (SKILL.md), Claude Code subagent definitions, house-style template, README, and `motif-skills.zip` |
