# Posterflow 2.0.0 (`motif-kit@4`)

Twelve liquid poster looks for your own images and clips, built from the reel reference (soft marbles, banded poster ink, streak melts, iridescent halos, mosaic water) and extended in the same direction. Each style takes one media input (`Source`); with nothing attached, a palette ink marble plays so thumbnails are never blank. No style flashes. Every motion is whole `Cycles / loop`, so loops close exactly.

| Style | Look | Cost |
| --- | --- | --- |
| Marble Flow | Looping flow-warp through colour bands and veins | 1 |
| Streak Melt | Masked directional drag, RGB split, sheared slabs | 1.6 |
| Ink Drag | Source carried along curl streamlines, then banded | 2.4 |
| Thin Film | Iridescent halos on every brightness edge | 1.8 |
| Mosaic Tide | Block-sampled, dithered colour stairs | 1 |
| Gill Lines | Engraved contour, parallel or radial lines; shadows thicken | 1.2 |
| Satin Pour | Refracted image lit with a stretched silk sheen | 2.2 |
| Dot Screen | Halftone carried by liquid flow | 1.2 |
| Tide Glint | Ripples + four-way glints on highlights | 2.6 |
| Oil Wash | Kuwahara painter, brush-like colour fields | 3 |
| Petal Fold | Mirror-folded petals poured through the flow | 1.2 |
| Aura Wash | Out-of-focus drifting bloom graded through the palette | 1.6 |

Also: **Poster Wash** (layer/finish effect), **Liquid Cut** (transition, exact at 0 and 1), sequences **Poster Reel** and **Soft Reel** (12 s, at most two shaders at once), four palettes (Tidal, Ember, Rosewater, Mineral) and two export presets.

Shared Lens controls on every style: Vignette, Exposure, Grain. Costs are declared estimates; on real GPUs Oil Wash, Tide Glint and Ink Drag are the heavy ones (reduce Brush radius / Smear taps / Steps first).

Limits: no state across frames, so flows are procedural rather than simulated.

Source layout: `styles/` for the three first styles are hand-written; the other nine are generated by `motifKits/tools/posterflow/build.mjs` from `body/*.glsl` + `head.glsl`, which also writes `manifest.json` and the sequences. Edit there, then run `node build.mjs`.
