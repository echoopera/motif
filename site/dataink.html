Set the numbers, watch the picture.

This is the real shader, running in your browser. Pick a graphic and drag its values. Every number printed in the figure is one of these sliders. In Motif the same sliders can be typed, keyframed, randomized or mapped to audio, so a dataset becomes a performance.

Tip. Move one slider slowly while the loop runs. The shapes respond to the value, not to the clock, so you can scrub a dataset like a timeline.

Eight figures.

All live. Each loops seamlessly; the bar under a figure is its loop position.

How the data gets in.

01

Values are parameters

Eight value sliders per style: stream weights, station gaps, waypoint widths, row levels, couplings. Type them, keyframe them, map them to audio bands.

02

Generators fill the gaps

Pick a pattern (peaks, seasonal waves, trend) and a label set (cities, stations, Greek, metals, months). Randomize deals a whole new dataset.

03

An image can be the data

Attach a photo to Heat Ledger and its brightness becomes the cell values, so a portrait reads as a ranking table.
