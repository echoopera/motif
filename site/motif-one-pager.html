Procedural motion studio · runs in the browser

Direct the motion. Tune every frame.

Motif is a procedural animation studio for type, shapes, particles, and physics. You direct it from Claude Code, Codex, or VS Code, and a team of 16 specialist agents builds it. Then you perfect it on a real timeline and ship to broadcast, Lottie, the web, or a live stage.

How it works

Direct, review, refine.

Motif has no chat box of its own. Your agent client connects through a local MCP bridge and edits a structured motion document with typed tools, so everything it builds is layered, editable, and reversible.

01 · Direct

Prompt from the client you use

Claude Code, Codex, VS Code, Cursor, or any MCP client. Select a word or a time range in Motif and the agents only touch that.

“More elastic on the second word.”
02 · Studio builds and checks

A team, not a single bot

The Director runs the job through studio stages. Specialists render frames, critique them against their craft, and leave timestamped notes for each other.

Particles and physics

A million points, still editable.

Particles, rigid bodies, and soft bodies are layers like any other. They sit on the timeline, respond to audio and pointers, and render the same way every time.

Emit from anything

Points, paths, shapes, glyph outlines, images by brightness, clones, or other particles on birth, death, and collision.

Forces with falloffs

Gravity, wind, curl-noise turbulence, vortex, attractors, flow fields, flocking, and Form, which springs particles into text or shapes.

Real-time physics

Any layer or letter can be a rigid body that falls, tumbles, and stacks. Ropes, cloth, and jelly shapes run on an XPBD solver.

Deterministic renders

Seeded, fixed-step simulations cache for instant scrubbing. Every render and every export reads the same cache.

Live mode

Visuals that listen.

Point Motif at an audio input, point at your assets, and give them reaction states. No node graph. When the set is over, record the take to the timeline and keep editing it.

Signals from any input

Interface channels, a mic, a file, or DAW loopback become level, frequency bands, onsets, beat, bar, and BPM. MIDI and clock too.

Reactors and states

Drive, Trigger, Switch, Accumulate, and Spawn reactions, grouped in states like calm, build, and drop. Or click a property and play a sound to learn a mapping.

Built for the stage

A fullscreen output window, 30 ms or less from sound to pixel, and a flash limiter on by default.

Engine

One document. Every editor.

Agents, the timeline, and code all edit the same Motion Document. Hand edits stay readable to the agents, and agent edits stay tunable by hand.

layers / motif-wordJSON
{
  "kind": "text",
  "text": { "content": "MOTIF", "split": "glyphs" },
  "modifiers": [
    { "type": "stagger", "delay": 0.12 },
    { "type": "spring",  "stiffness": 180, "damping": 12 },
    { "type": "overlap", "frames": 3 }
  ],
  "reactors": ["kick-pulse"],
  "notes": [{ "t": 1.2, "to": "@animator" }]
}

Procedural first, keyframes second

Modifiers and effectors generate motion; keyframes shape it. Bake any channel to keys and unbake it later.

Deterministic to the frame

Seeded noise, closed-form springs, and cached simulations render the same frame everywhere.

Real typography

Split by line, word, or glyph. Animate variable-font axes. Convert to outlines for morphs and particles.

Every change is a diff

Export

From app screens to air.

Every export renders from the same engine as the editor, so what you tuned is what ships: to phones, sites, edit bays, and broadcast.

Lottie JSON · .lottie

Lottie, native where it counts.

Shapes, trims, precomps, masks, cameras and eases map to native Lottie. Only what has to be baked gets baked.

  • Lottie-safe mode flags the cost of each feature while you author.
  • A parity check renders your export in lottie-web and dotlottie-web and diffs it against Motif before download.
  • Key simplification and shared glyph outlines keep a 5 s title card under 100 KB.

Connect

Bring your own agent.

A local bridge exposes Motif as an MCP server. Pair once with a 6-digit code; the bridge only listens on your machine. These are the planned setup commands.

claude mcp add motif -- npx motif-bridge

command = "npx"
