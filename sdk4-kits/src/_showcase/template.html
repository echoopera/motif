Evidence

How these loop

Bounded periodic phase

Time enters only as θ = 2π·fract(u_p). Every temporal harmonic is an integer multiple of θ; static angles and phases are seeded constants. Particle lifecycles and cell divisions are deterministic closed choreography, not simulation.

Proven field classes

Each scene function is labelled exact, bound, implicit, density or glow, and only a matching renderer draws it. Lipschitz constants for the gyroid, warp, Möbius ribbon and folded plate are derived in the kit source, not tuned.

One tone map

Scenes write linear HDR; one output pass adds bloom, fringe, vignette and a single tone map. Volumes integrate with ray-step length so exposure holds across quality settings.

Known limits: no persistent simulation exists in the SDK contract (cell lifecycles are analytic); glass in Sacred Lattice and After Cyber is an approximation, not refraction; device GPU timings are not measured here.
