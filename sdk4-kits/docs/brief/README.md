# Motif SDK 4 Agent Handoff

Nine project PRDs and nine engineering starters define the next generation of the supplied WebGL studies as seamless infinite animations. Each project targets a nine-style kit, with one flagship validated first and eight structurally differentiated derivatives. This is a proposed scope based on the established kit workflow; the user can reduce the variant count without changing the hero requirements.

Start with AGENT-START.md. ENGINEERING-FOUNDATION.md contains shared SDK, rendering, loop, performance and QA rules. Each numbered folder contains PRD.md, ENGINEERING-STARTER.md, REFERENCE.png and PROTOTYPE.frag. PLAYBOOK.md is included as the source of local SDK requirements. REFERENCE-BOARD.jpg shows the nine implemented directions together.

The installed SDK source was not included in this handoff. Its schema, helper signatures and runtime behavior must be verified by the implementing agent. No production shader kits or device-performance approval are claimed by these planning documents.
