# Agent implementation assignment

You are implementing one of nine Motif Kit SDK 4.0 projects. Select the assigned numbered project folder; read its PRD.md and ENGINEERING-STARTER.md, then ENGINEERING-FOUNDATION.md and PLAYBOOK.md. The required outcome is a nine-style kit of visually refined, seamlessly looping infinite animations. Treat PNG and fragment sources as prototypes rather than a finished kit.

Do SDK discovery first and verify the real schema and helpers. Implement one complete flagship vertical slice before deriving variants. Use bounded periodic phase, stable identities, proven field bounds and step-normalized volumetrics. Do not rely on persistent graph feedback. Every parameter must visibly work. Do not replace animation with posters or claim real-device performance from software rendering.

Work through the stated implementation sequence and delivery gates. Produce the pack, source, animated one-page product page, stills, loop films and QA evidence. If a runtime feature is missing, ship the best compatible approximation and record a proposal; do not change the runtime. Ask for direction only when a material unresolved decision changes the project goal. No delegation is required by this assignment.
